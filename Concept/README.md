# Concept

The file [AirPods-Bubble-Product-Concept.txt](AirPods-Bubble-Product-Concept.txt) is the original product concept (concept version 1.0, dated 2026-09-29).

That document describes the **intended product**. Features such as keeping ANC on, keeping each person’s music, and automatic voice ducking are goals. They are not implemented and are not proven on public Apple APIs.

The software repository version is **0.1.0** (setup only). Engineering sequence is in [../PROJECT_PLAN.md](../PROJECT_PLAN.md).
